# Dashboard de Análises de Assinaturas e Vendas

Este repositório contém um projeto de **análise de dados e visualização em Excel**, desenvolvido com o objetivo de explorar insights de negócio a partir de dados de assinaturas e vendas.  
O projeto faz uso de **tabelas dinâmicas**, **gráficos interativos** e **indicadores de desempenho (KPIs)** para apoiar a tomada de decisão.

---

## 🧠 Objetivo do Projeto

Criar um **dashboard gerencial** capaz de responder perguntas estratégicas de negócio, facilitando a análise de performance e comportamento dos assinantes/clientes.

---

## 💡 Perguntas de Negócio Respondidas

1. **Qual é a receita total gerada por tipo de assinatura?**  

2. **Qual é a taxa de renovação automática entre os assinantes?**  

3. **Quantos assinantes adquiriram passes adicionais de Minecraft e qual o impacto financeiro disso?**  

---

## 🧾 Estrutura do Projeto

- **`dashboard_vendas.xlsx`** → Dashboard em Excel com visualizações e KPIs interativos.  
- **`README.md`** → Documento explicativo sobre o projeto e suas análises.

---

## 📈 Principais Insights

- O **plano Ultimate** apresenta a maior receita total.  
- Cerca de **X%** dos assinantes utilizam **renovação automática**, indicando boa retenção.  
- Os **passes adicionais** geram impacto financeiro relevante, especialmente o *EA Play*.

---

## 📂 Como Visualizar

1. Faça o download do arquivo `dashboard_vendas.xlsx`.  
2. Abra no **Microsoft Excel**.  
3. O Dashboard estará disponível para visualização.
